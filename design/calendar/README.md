# 日历选中态 · 方案

首页日历里，连续选中的几天（区间）和单选的一天，现在都不够显眼：区间只有一层浅灰底（`.cell.inrange`），单选只有一圈 2px 强调色描边（`.cell.sel`）。这份稿子给出六个候选做法。

## 打开方式

直接双击 `01-selected-state.html`。单文件，无构建步骤，无外部请求，离线可用，右上角可以切浅色和深色。

每个方案下面都是同一份 2026 年 10 月的日历：**15–19 日是连续选中的区间，21 日是单选的一天**，数据取自本机 `data/atracker.db`。

## 六个方案

**方案 0 现状（对照）**。区间浅灰底，单选 2px 描边。

**方案 A 区间上下双线 + 端点封口**。区间用上下两条 2px 强调色线夹住，首格补左边线、末格补右边线，形成一个连续的框；单选那天用 2px 整圈强调色加 8% 底色。框是线不是面，纸面还是干净的，最贴热敏小票的调子。

**方案 B 区间浅底 + 单选反白**。区间 16% 强调色底，单选那天整格铺满强调色、文字反成纸色。最醒目，代价是单选那格在整页里非常跳。**采用了这一套的底色，但单选没有用满格铺色**：整格铺红在首页太抢眼，实际实现改成单选和区间用同一个 16% 浅红底，单选再加一圈 1px 红边，日期数字保持红色加粗。代码在 `packages/web/src/receipt.css` 的 `.cell.inrange` 和 `.cell.sel`。

**方案 C 区间书签边 + 单选压印**。区间用左侧 3px 竖条（末格再加一道右竖条），单选那天用内描边加一道向下的硬阴影，像在纸上压了个章，日期数字同时放大加粗。

**方案 D 整段压印 + 单选带色底边**。区间用黑线上下夹住（首尾补左右线），底色是极浅的灰；单选那天黑框加一道红色底边。和纸面是黑白关系，只在最需要强调的地方用一次红。

**方案 E 骑缝色条 + 角标**。区间用浅灰底加一条 5px 底部强调色横条；单选那天加边框、浅底、右上角一个圆点角标。

**方案 F 整列粗边 + 单选满格**。区间用 10% 底色加左右 1px 强调色边，首格左边线和末格右边线加粗到 3px；单选那天整格铺满强调色、文字反白。

## 实现上的差别

所有方案都只用现有的 CSS 变量（`--accent`、`--ink`、`--wash`），深色主题自动跟着变，不需要新颜色。

- **方案 A 和 F 需要改组件**：区间首格加 `first`、末格加 `last` 两个 class，才能把区间的左右边封上。
- **方案 B、C、D、E 只改样式**，组件结构不动。

## 现在的选择行为

点一天选中，再点另一天成区间，再点一次重置。区间是闭区间，两端都是选中的。单选和区间用的是同一个 `.cell.sel` 与 `.cell.inrange` 状态。
