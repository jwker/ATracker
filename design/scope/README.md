# 当前范围提示 · 方案

首页标题行里那行「当前范围 2026-10-02 → 2026-10-03 / 2 天」字号 9px、颜色是灰的，和右边的合计数一样弱。但范围是这一页最重要的上下文：下面的四桶、来源 × 模型、目录用量、模型用量全跟着它走，所以它值得被单独看见。

## 打开方式

直接双击 `01-range-label.html`。单文件，无构建步骤，无外部请求，离线可用，右上角可以切浅色和深色。

每个方案下面都是同一段内容：TOKEN 四桶的四行，范围是 2026-10-02 到 2026-10-03。

## 六个方案

**方案 0 现状（对照）**。标题行里一行小灰字。

**方案 A 独立范围条**。范围从标题行里拿出来，单独占一条带边框的横条：左边「范围」小标签，中间是范围，右边是「2 天」红框徽章，最右是「清除」。范围成了有边界的一块东西，也不占标题行的宽度。

**方案 B 面包屑**。上级「2026 年 10 月」是浅灰的，当前选中的那段墨色加粗，天数是小红框徽章。一眼能看出「这是在哪个月里选的」，单选一天的时候层级只有一级略显多余。

**方案 C 强调色胶囊**。范围做成强调色底、纸色字的胶囊，天数用描边徽章跟在后面。最像贴上去的标签，但这一页的强调色被范围占了，下面其他地方的红会相对弱。**已采用**：首页有两处显示范围（四桶小节标题、月历小节标题右侧），两处都用这个胶囊，抽成 `packages/web/src/components/ScopeTag.tsx` 共用。胶囊右边带一个「清除」，点它回到整月。

**方案 D 结账行**。照搬首页四桶那种「标签 … 点线 … 值」的行，单独一行放在最上面，下面一行小字写「共 2 天 · 合计 3.84 亿 token · ¥6.42」。和这一页其他地方的排版完全一致，是最不动声色的加强。

**方案 E 标题行内强化**。不加新块，只把范围从 9px 灰字换成墨色 10px（去掉字距），箭头用强调色，天数用强调色小字，标题行下边框从 1px 加到 2px。改动最小，位置不动。

**方案 F 范围条带合计**。在方案 A 的基础上把范围条改成左边一道 3px 红边，右侧补上这个范围的合计 token 和成本。范围和结果在同一行。

## 实现上的差别

- **方案 A、D、F** 要在组件里新增一个块，范围从 `sec-h` 里搬出来。
- **方案 B、C、E** 仍然放在标题行里，只改文字和样式，`HomeView.tsx` 里那一行拆成几个 span 就行。
- 没选日期时的范围是「2026 年 10 月 / 31 天」，各方案都要能放下这一种：面包屑会退化成一级，胶囊和范围条直接换成月份文字。

## 顺带

范围目前没有「清除」的入口，只能在日历上再点一次同一天来取消。方案 A 和 F 带了一个「清除」，如果选这两套，前端要接上一个取消选择的按钮。

## 范围切换按钮

顶部大字可以在「当前范围」和「全部记录」之间切。按钮放在「TOKEN 总量 / 当前范围」那行文字的后面，
高度要贴住那行 9.5px 的小字，长度要够、看着像个能按的东西。

稿子在 `02-swap-button.html`，五个方案，每个都给了正在看范围和已经切到总量两个状态。

| 方案 | 做法 | 说明 |
| --- | --- | --- |
| 0 现在的 | 13px 纯图标方块，23.8 × 22.2 px | 比旁边那行字高出一截，偏窄 |
| A 压扁的长条图标 | 高度贴住文字，宽度拉到 52px 以上 | 还是纯图标，靠长度和悬停变色表明能按 |
| B 图标 + 当前口径 | 按钮上写「当前范围」或「全部记录」 | 不用点就知道看的是哪段，但和标签上的字重复 |
| C 图标 + 目标口径 | 按钮上写「看总量」或「看范围」 | 点之前就知道会发生什么，最不容易误读 |
| D 分段切换器 | 「当前范围 │ 全部记录」两段，选中的反白 | 两种口径同时可见，语义最明确，宽度最大 |
| E 纯文字按钮 | 不要图标，直接写「看总量」 | 最省地方、语义最直白，离图标远一点 |

「当前口径」和「目标口径」两种写法要分清：前者按钮上写的是现在看的是什么，后者写的是点了会变成什么。

**已采用方案 D**，并按反馈把标签里重复的「/ 当前范围」去掉了：那行现在只写「TOKEN 总量」，
两个口径由切换器自己说。切换器两段的高度和那行小字齐平，选中的那段反白。
