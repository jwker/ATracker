# 线框原型

低保真线框，用来评审 `PRD.md` 里的结构与交互，不是最终视觉设计。角标上的数字对应 PRD 的章节号。

```
index.html         入口
home.html          主页面（日历）
conversation.html  对话页
log.html           日志页
wireframe.css     样式
data.js           假数据（按天、按目录、按模型、按会话与轮次）
app.js            渲染与交互
```

直接用浏览器打开 `index.html` 即可，不连网、不用构建。

## 可以点的部分

| 位置 | 行为 |
| --- | --- |
| 顶栏「单位」 | 在中文、缩写、千分位三种单位之间切换，全页所有 token 数字跟着变 |
| 顶栏「切换到暗色」 | 整页换配色 |
| 日历月份箭头 | 上一个月 / 下一个月 |
| 日历「今天」 | 回到当前月份并清除选中 |
| 日历格 | 点一天选中，再点另一天形成区间，再点同一天取消 |
| 日历图例 | 点目录名，在格子里只看这个目录的用量，再点取消 |
| 详细数据里的来源 × 模型交叉表 | 点一个格子跳到对话页，并按这个来源和模型筛选 |
| 详细数据里的目录条形 | 点一行跳到对话页，并选中那个目录 |
| 顶栏的页面按钮 | 三个页面之间跳转 |
| 日志页的批次行 | 点一行把日志流筛到那一批，再点取消 |
| 日志页的级别 / 来源 / 关键字 | 过滤日志流 |
| 日志页「重新扫描」 | 触发一次手动扫描 |
| 对话页左栏会话 | 切换右栏显示的会话 |

## 数据说明

`data.js` 里生成的是示意数据，覆盖 2025-11 到 2026-10。生成逻辑和真实采集结果同构：每天有总量、按目录的拆分、按模型的拆分；每个目录下有几个会话，每个会话有若干轮，每轮有输入、输出、缓存命中和所用模型。

交叉表里每个来源的模型分布是按各来源的常用模型生成的假数据（codex 主用 gpt 系列、claude-code 主用 opus、pi 主用 deepseek 和 MiniMax、opencode 主用 MiniMax、dsh 主用 deepseek 和 glm），这样点格子下钻能对上会话。

价格用 `config/pricing.json` 里那张表的同一套单价，人民币按固定汇率 6.5 折算。`MiniMax-M3.1-Flash` 在价格表里没有条目，用来演示「未配置价格」的处理。
