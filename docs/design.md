# 界面设计

看板的样子不是随便选的，几个约束决定了它现在长这样。这份文档记录这些决定的理由，改界面之前先读一遍。

## 热敏小票风格

整体是一个小票的隐喻：等宽字体、点线分隔、顶部和底部是撕纸齿、正文像打印出来的流水。原因是这个工具展示的就是「今天打了多少流水」，小票的视觉能直接对上数据模型——一行一条记录，末尾合计。

主题（风格）和明暗是两个独立维度。现在的主题 id 是 `receipt`，明暗各有一套变量，都在 `packages/web/src/receipt.css` 开头。切换明暗时主题不变，加新主题时两套明暗都要给，互不影响。变量清单见[架构的界面主题一节](architecture.md#5-界面主题)。

## 模块不写标题

页面上每个模块直接显示内容，不写「详细数据」「模型分布」这类标题。需要说明范围的地方用一行小字写口径，比如「2026 年 10 月 · 31 天」。

小票本来就没有章节标题，加回去会让版面变得像普通后台。

## 四桶一行

四个桶（输入、输出、缓存命中、缓存写入）横排一行，不堆成四行。堆成四行时总账页要空出一大块高度，扫一眼的成本也更高。

## 圆形图表不用

没有饼图、环形图。比例用横向长条加百分比数字表示：分母和分子都写出来，读者可以自己核对，而且长条之间可以直接比长度。

## 柱状图的柱子数

- 按天：一天一根，柱子多的时候间隔自动收窄，最小 2px 宽，不会画成负宽度。
- 按月：全期视图下 145 天按天画既排不下也看不清，改成按月，一个月一根。
- 按小时：24 根，固定宽度。

用量最大的那根标红，其余灰色。空柱子保留位置但不画高度，读者能看出那天没有数据，而不是那天不存在。

## 颜色的含义

| 用途 | 颜色 |
| --- | --- |
| 强调 | 蓝，用于选中态、主按钮、当前值 |
| 正向 | 绿，用量上升 |
| 负向 | 红，用量下降或错误 |
| 目录 | 每个目录一个固定颜色，跟随实体不跟随排名 |
| 来源 | 每个 agent 一个固定颜色，和目录色板是两套 |

目录颜色跟随实体很重要：同一个项目在两次查询里排名变了，颜色不能跟着变，否则读者会以为是另一个项目。实现在 `packages/core/src/palette.ts`。

## 分享卡片

三处「分享卡片 →」弹出一个弹窗，只显示当前入口对应的那一张卡，导出 1080×1920 的 PNG。

| 入口 | 卡片 | 柱子 |
| --- | --- | --- |
| 总账 | 全期卡 | 按月 |
| 月度 | 范围卡 | 按天 |
| 今日 | 今天卡 | 按小时 |

卡片用 canvas 直接画（`packages/web/src/card/render.ts`），不引第三方截图库：网页版和桌面版走同一条路，输出尺寸固定 1080×1920，不受屏幕 DPI 影响。

纸的高度跟着内容走，不是固定高：模型多的时候纸自己拉长，最多 6 行，超过的归到「其他」。

卡片上不出现设备名和日志链接，只留版本号。发到手机上时那些信息没有意义。
